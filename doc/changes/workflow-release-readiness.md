# 新增发布就绪度检查工作流

`gitlink-cli workflow +release-readiness` 新增了发布前门禁检查能力，用于判断一次发布是否可以推进、需要人工复核，还是应先阻塞处理。命令既支持通过 flags 传入版本号、变更摘要、测试结果、制品状态、已知阻塞项、回滚方案和依赖风险，也支持从 JSON 文件读取完整门禁输入。

该功能与发布说明生成不同，重点不是撰写 changelog，而是把发布前散落的信息转成可审查的 gate 结论。评分规则会对缺失版本号、缺少变更摘要、失败测试、缺失制品、已知阻塞项、破坏性变更但没有回滚方案、依赖风险等情况扣分，并输出 `pass`、`review` 或 `block`。结果支持 `table`、`markdown` 和 `json`，适合终端发版检查、发布评审记录或 CI 脚本消费。

命令保持只读安全边界，不会创建 tag、Release、附件或远端评论。本次变更包含命令注册、flags/JSON 输入解析、门禁评分、中文和英文输出、README 示例、中文 README 说明以及单元测试；测试覆盖通过、阻塞、flags 解析、JSON 输入、markdown/table 渲染和 shortcut 注册。
